# ตารางวันหยุดและตารางงานพนักงาน

เว็บเพจไฟล์เดียว (`index.html`) ใช้ลงวันหยุดและจัดตารางงานบาริสต้า ไม่ต้องติดตั้งอะไรเพิ่ม

## เปิดใช้บน GitHub Pages
1. อัปโหลด `index.html` ไว้ที่หน้าแรกของ repository
2. ไปที่ Settings → Pages แล้วเลือก Branch `main` และโฟลเดอร์ `/ (root)` จากนั้นกด Save
3. รอประมาณ 1 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`
   - เปิดหน้าตารางงาน: เติม `#work` ท้ายลิงก์
   - เปิดหน้าลงวันหยุด: เติม `#leave` ท้ายลิงก์

## การบันทึกข้อมูล
ข้อมูลทั้งหมด (พนักงาน สาขา วันหยุด และตารางงาน) เก็บอยู่ในไฟล์ `index.html`
- ระหว่างแก้ไข ระบบจะเก็บข้อมูลไว้ในเบราว์เซอร์เครื่องที่ใช้แก้
- กด **"บันทึกและแชร์"** เพื่อดาวน์โหลด `index.html` ที่มีข้อมูลล่าสุด
- นำไฟล์นั้นไปอัปโหลดทับไฟล์เดิมใน GitHub ทุกคนที่เปิดลิงก์จะเห็นข้อมูลใหม่
- ถ้ามีคนแก้พร้อมกันหลายเครื่อง ไฟล์ที่อัปโหลดทีหลังจะทับไฟล์ก่อนหน้า ควรให้มีคนอัปโหลดเพียงคนเดียว
